DATABASE IMPLEMENTATION

Implemented JDBC repositories for User and Friendship entities, supporting CRUD operations.

PostgreSQL is used for persistent data storage. User IDs are automatically generated by the database.

SQL queries use PreparedStatement to prevent SQL injection.

REPOSITORY CONFIGURATION

The application supports three repository types: MEMORY, FILE and DATABASE.

The repository type is selected through config.properties without modifying the source code.

Database credentials are stored in config.properties, which is excluded from Git. A config.example.properties file is provided.

FRIENDSHIP DELETION

When a user is deleted, all associated friendships are also removed.

EXCEPTION HANDLING

SQLExceptions are wrapped in RepositoryExceptions.

Database errors are handled gracefully, displaying meaningful messages without stack traces.
